# Como clonar o repositório "Source-Priston" no seu computador

Guia passo a passo para iniciantes. Seja bem-vindo! 😊

---

## O que você vai fazer (resumo)

Você vai copiar o projeto (que está no site GitHub) para o seu computador.
Esse processo se chama **clonar**. É como baixar uma cópia do projeto para
você trabalhar nele.

---

## Antes de começar — 2 coisas que você precisa

1. Uma conta no GitHub (você já tem: **LucasHanma-tales**).
2. **Aceitar o convite** que o administrador (othiagob) te mandou.

### Como aceitar o convite

1. Abra o seu e-mail e procure uma mensagem do GitHub com assunto parecido
   com "othiagob invited you to collaborate".
2. Clique no botão ou link **"View invitation"** (Ver convite).
3. Na página que abrir, clique em **"Accept invitation"** (Aceitar convite).
   - Se não achar o e-mail, abra `https://github.com/notifications` ou peça
     o link direto ao administrador.
4. Pronto! Agora você é colaborador do projeto. (O administrador ainda vai
   ajustar o seu nível de acesso.)

> ⚠️ **Importante:** só siga para o próximo passo **depois** de aceitar o
> convite. Se não aceitar, o projeto não vai aparecer para você.

---

## Passo 1 — Instalar o GitHub Desktop

O GitHub Desktop é um programa que deixa tudo mais fácil, sem precisar
digitar comandos.

1. Abra o navegador (Chrome, Edge, etc.) e acesse: **https://desktop.github.com**
2. Clique no botão **"Download for Windows"**.
3. Quando terminar de baixar, abra o arquivo (normalmente fica na pasta
   "Downloads", com um nome parecido com `GitHubDesktopSetup-x64.exe`).
4. Siga a instalação (é só clicar em "Avançar"/"Next" e "Instalar"/"Install").
5. Abra o programa **GitHub Desktop**.

---

## Passo 2 — Entrar com a sua conta

1. Ao abrir, o programa vai perguntar se você quer entrar. Clique em
   **"Sign in to GitHub.com"** (Entrar no GitHub.com).
2. Vai abrir o navegador pedindo autorização. Clique em **"Authorize desktop"**
   (Autorizar).
3. Volte para o programa — ele deve mostrar o seu nome de usuário.

---

## Passo 3 — Clonar o projeto

1. No GitHub Desktop, clique no menu **File** (Arquivo) no topo.
2. Clique em **Clone repository...** (Clonar repositório).
   - Atalho: você também pode apertar **Ctrl + Shift + O**.
3. Na janela que abrir, deixe marcada a aba **"GitHub.com"**.
4. Na lista, procure por **othiagob/Source-Priston**. Repositórios privados
   aparecem com um cadeado 🔒.
   - Se a lista estiver grande, use o campo de busca e digite "Source-Priston".
   - Se ele **não aparecer**, volte para "Antes de começar" — provavelmente
     você ainda não aceitou o convite ou não entrou com a conta certa.
5. Embaixo, em **Local path**, escolha onde salvar no seu computador
   (pode deixar o padrão, ou clicar em "Choose..." para escolher outra pasta).
6. Clique em **Clone**.
7. Aguarde alguns segundos enquanto ele baixa os arquivos.

---

## Passo 4 — Conferir se deu certo

1. Abra a pasta que você escolheu. No GitHub Desktop, clique em
   **Repository → Show in Explorer** (Repositório → Mostrar no Explorer).
2. Você deve ver os arquivos do projeto dentro dela. 🎉

**Parabéns!** Você clonou o repositório. Agora o projeto está no seu
computador e você pode explorar os arquivos.

---

## E agora? (próximos passos)

Depois você vai aprender a:

- Fazer alterações e "salvar" (commit);
- Enviar suas alterações para o GitHub (push);
- Pedir para o administrador aceitar as suas mudanças (Pull Request).

Por enquanto, explore os arquivos e se familiarize. Quando quiser, o
administrador te ensina o próximo passo.

---

## Problemas comuns

| Problema | Solução |
|---|---|
| O projeto não aparece na lista ao clonar | Você ainda não aceitou o convite, ou entrou no GitHub Desktop com outra conta. |
| Erro ao entrar | Verifique se o e-mail e a senha do GitHub estão corretos. |
| Não acha o arquivo baixado | Procure na pasta "Downloads". |
| A instalação não abre | Clique com o botão direito no arquivo e escolha "Executar como administrador". |
